What changed from the pre-read map

  • PII is split by code before any AI call; the name comes from the form
  • Scoring is split: AI judges the evidence, code does the maths, bands and routing
  • Borderline is a new human step: brief only, Arjun picks Invite or Reject
  • Neon database shown as its own lane; Resend sends only after the human gate

The Cut, built in

  • No auto-reject, no bulk send (Checks 06 + 09)
  • Every email needs a confirm click; a sent email cannot be re-sent
  • Evidence-or-zero and quote checks stop keyword stuffing
  • Every quantified claim is flagged “verify in interview”
